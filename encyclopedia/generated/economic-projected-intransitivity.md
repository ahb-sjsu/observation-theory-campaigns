# Projected Intransitivity

**id.** economic-projected-intransitivity
**kind.** result
**volume.** Geometric Economics, Volume 4 of the Geometric Series

## definition

Preference on the full complex, ordering alternatives by path cost from the current state under a fixed metric, is transitive. A projected preference can cycle when the projection compares different pairs on different dimensions.

**Example.** The volume's proof uses x = (3, 1, 5), y = (5, 3, 1) and z = (1, 5, 3). On dimensions 1 and 2 y beats x, on 2 and 3 z beats y, and on 1 and 3 x beats z, which is a cycle.

## conditions

- Transitivity on the full complex needs a fixed metric and a single reference state, so that path cost is one real-valued function of the alternative.
- The cycle in the proof arises only when the projection is context dependent, comparing each pair on a different subset of dimensions.
- The volume reads Tversky's intransitivity experiments this way. That reading is an interpretation and no fitted test of it is reported.
