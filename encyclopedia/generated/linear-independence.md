# linear independence

**id.** linear-independence
**kind.** concept

## definition

Vectors none of which is a linear combination of the others, so that the only combination giving zero has every scalar zero. The rank counts the independent columns. Primer L section L.4.

**Example.** (1, 2) and (2, 4) are dependent, the second being twice the first, and (1, 2) and (2, -1) are independent.
