## definition

The equal protection gauge group is generated by transformations that change a party's protected-class attribute while preserving all facts, all legal attributes and all Hohfeldian bonds. A legal evaluation satisfies equal protection if and only if it is unchanged by every element of this group.

**Example.** Changing a party's sex twice returns the original case, so that generator has order 2. If the original case draws 60 months, the case with the sex changed must also draw 60 months.
