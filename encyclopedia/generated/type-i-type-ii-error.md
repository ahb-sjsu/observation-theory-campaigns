# type I and type II error, power

**id.** type-i-type-ii-error
**kind.** concept

## definition

A type I error rejects a true null, at the rate the threshold fixes. A type II error fails to reject a false null, and power is one minus that rate, growing with the sample size and the size of the effect. Primer S section S.7.

**Example.** With two values per group the smallest possible p-value is one sixth, so at a threshold of 0.05 the test has no power at all.
