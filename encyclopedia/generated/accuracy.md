# accuracy

**id.** accuracy
**kind.** concept

## definition

The fraction of all rows a classifier labels correctly, the score most easily fooled, since predicting the majority class for every row scores the majority's share. Balanced accuracy averages the per-class recalls instead. Primer S section S.9.

**Example.** On 1000 rows with 50 positives, calling every row negative scores 0.95.
