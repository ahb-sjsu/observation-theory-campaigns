# pseudo-random generator

**id.** pseudo-random-generator
**kind.** concept

## definition

A deterministic rule that produces a sequence indistinguishable from chance from a starting value, the seed, so that a simulation which records its seed reruns to the last digit and one that does not cannot. Primer S section S.11.

**Example.** A generator started from seed 0 gives the same draws on every run, and a different seed gives different ones.
