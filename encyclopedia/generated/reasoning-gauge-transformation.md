# Gauge transformation of a problem description

**id.** reasoning-gauge-transformation
**kind.** concept
**volume.** Geometric Reasoning, Volume 3 of the Geometric Series

## definition

A map $\tau$ on problem descriptions that changes the surface presentation and keeps the task-relevant content. With $\pi$ the projection from descriptions to content, $\tau$ is a gauge transformation exactly when $\pi(\tau(x)) = \pi(x)$ for every description $x$. Such maps form a group under composition.

**Example.** Swapping the genders of the actors in a scenario changes the description and not who did what to whom, so it is a gauge transformation, while changing what was done is not.

**Known as, or related to prior art.** Gauge transformations of physics, used by analogy. The same structure is a group action whose orbits are the classes of equivalent descriptions.

## conditions

- It presupposes a content projection, a decision about which features of a description are task-relevant. The volume does not construct this projection for its benchmark and relies on rewrites judged to preserve content.
- The group claim needs every transformation to have a content-preserving inverse, which the definition asserts.
- The standard applied to gauge transformations is invariance, an identical output, and not robustness, a nearby one.
