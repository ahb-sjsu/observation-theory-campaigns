# metric feature versus heuristic error

**id.** metric-feature-versus-heuristic-error
**kind.** concept
**volume.** Geometric Economics, Volume 4 of the Geometric Series

## definition

The volume's two-way classification of behavioral phenomena. A metric feature follows from the manifold's metric and would persist for an agent with perfect information. A heuristic error is a different evaluation of the same state under a different description. Gauge invariance is the criterion that separates them.

**Example.** In the volume's table loss aversion is a metric feature. Choosing differently between a 90 percent survival rate and a 10 percent mortality rate is a heuristic error, since both describe one state.

## conditions

- The table lists loss aversion, reference dependence, the endowment effect, hyperbolic discounting and status quo bias as metric features. It lists framing, anchoring, availability bias and the sunk cost fallacy as heuristic errors.
- The classification rests on the posited metric. It is not an observed property of the phenomena.
- The volume gives a test and reports no run of it. Loss aversion should resist debiasing while framing effects should shrink when the attribute vector is made explicit, and identical responses to debiasing would show the classification wrong.
