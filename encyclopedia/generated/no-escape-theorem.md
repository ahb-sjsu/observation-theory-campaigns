# No Escape Theorem

**id.** no-escape-theorem
**kind.** result
**volume.** Geometric Ethics, Volume 2 of the Geometric Series

## definition

For an agent whose pipeline satisfies four requirements (mandatory canonicalization, evaluation grounded in physical observables, complete audit, and strong external verification), relative to the declared grounding and transformation group, a re-description that preserves the grounded values leaves the evaluated output unchanged, and an output that violates the constraints is blocked or flagged by audit.

**Example.** If x and x' describe the same situation, the canonicalizer gives C(x) = C(x'). The evaluation reads only the grounded values of the canonical form, so it returns the same output for both, and renaming alone changes nothing.

## conditions

- The theorem is conditional on Requirements 1 to 4 and on an adequate grounding. It is as strong as those premises.
- It blocks cognitive escape routes only. Physical attacks such as sensor spoofing and hardware tampering, and an incomplete grounding, are outside its scope.
- The volume reports that a version of the I-EIP monitor it proposes for verification failed three sealed preregistrations. It calls that requirement of its architecture an engineering target, not a verified component.
- Averaging over paraphrases met a preregistered invariance bar on natural rewordings only. Euphemistic rewrites of flagged content still passed, so the volume says this is not adversarial robustness.
