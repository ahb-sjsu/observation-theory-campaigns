# GPA Irrecoverability Theorem

**id.** gpa-irrecoverability-theorem
**kind.** result
**volume.** Geometric Education, Volume 9 of the Geometric Series

## definition

On a connected learner manifold of dimension at least 2, a continuous surjective scalar assessment G is not injective, so distinct learner states share one score. No function then maps the score back to the state. For k scalar assessments with k below the dimension d, the joint assessment is still not injective.

**Example.** With the volume's weights (0.60, 0.25, 0.05, 0.05, 0.03, 0.02), the states (0.5, 0.4, 0, 0, 0, 0) and (0.4, 0.64, 0, 0, 0, 0) both score 0.40, since 0.30 + 0.10 and 0.24 + 0.16 are equal. For six dimensions the level set of any score has dimension 5.

## conditions

- The only restriction on G is continuity. The printed proof takes a regular value of G and applies the preimage theorem, so the level set has dimension d minus 1.
- It is a statement about the map and holds for the six learner dimensions only if they are independent dimensions of a real space of learner states, which the volume posits.
- The estimate that one grade value is compatible with 100 to 1000 qualitatively distinct profiles is called a rough estimate. No computation is printed.
- Scores that all project mainly onto domain knowledge are correlated, so a battery of them spans fewer independent dimensions than it has scores.

Conditions are curated in `volumes/geometric-education.toml` rather than read from a record.
