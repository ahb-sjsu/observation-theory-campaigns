# column space

**id.** column-space
**kind.** concept

## definition

The span of a matrix's columns, which is the set of every output the matrix can produce, of dimension equal to the rank. Primer L section L.4.

**Example.** The matrix with rows (1, 2) and (2, 4) has column space the line of multiples of (1, 2).
