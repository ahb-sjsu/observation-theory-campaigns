# span

**id.** span
**kind.** concept

## definition

The set of all linear combinations of a set of vectors. One nonzero vector spans a line, two off one line span a plane, and the columns of a matrix span its column space. Primer L section L.1.

**Example.** (2, 4) lies in the span of (1, 2), being twice it, and (3, -1) does not.
